# Złoty Plan

Бюджет в злотых: конверты по ценам Польши, учёт трат, цели, фонд редких трат, история и копия в Excel.

- Сайт: https://gridine644-ops.github.io/zloty/
- APK для Android (всегда последняя версия): https://github.com/gridine644-ops/zloty/releases/latest/download/ZlotyPlan.apk

Данные хранятся только на твоём устройстве. В этом репозитории их нет.

APK собирается автоматически после каждого обновления (`.github/workflows/apk.yml`, папка `app/`).
Ключ подписи `app/zloty.keystore` лежит в открытом виде: этого хватает для личного приложения, для Google Play нужен закрытый ключ.
